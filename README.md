# Task Manager Bot

Telegram-бот для управления задачами с приоритетами, архивом и напоминаниями о дедлайнах.

## Возможности

- Добавление задачи: название, приоритет (1-5), срок в формате `ГГГГ-ММ-ДД ЧЧ:ММ`
- Список активных задач, отсортированный по приоритету
- Отметка задачи выполненной и удаление прямо из списка
- История выполненных задач с восстановлением и очисткой архива
- Напоминание за 10 минут до дедлайна
- Данные каждого пользователя хранятся отдельно

## Команды

| Команда | Действие |
|---|---|
| `/start` | Главное меню |
| `/add` | Добавить задачу |
| `/tasks` | Активные задачи |
| `/history` | Архив выполненных |

## Стек

Python 3.12, aiogram 3, aiosqlite, python-dotenv

## Структура

```
main.py        запуск бота и цикл напоминаний
handlers.py    обработчики команд и кнопок
database.py    работа с SQLite
keyboards.py   клавиатуры
config.py      загрузка настроек из .env
```

## Запуск

```bash
git clone https://github.com/ProstoArtem1/TaskManagment.git
cd TaskManagment
pip install -r requirements.txt
cp .env.example .env
```

Впишите в `.env` токен бота, полученный у @BotFather, затем:

```bash
python main.py
```
